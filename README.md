# 🤖 AI-Insight-Chatbot

An interactive chatbot web application developed using Python Flask and modern web technologies. The chatbot provides instant responses to questions related to Artificial Intelligence, Machine Learning, Generative AI, Large Language Models (LLMs), Prompt Engineering, Retrieval-Augmented Generation (RAG), Python, AWS, SQL, Data Science, and Web Development.

---

## 📌 Project Overview

AI-Insight-Chatbot is a lightweight educational chatbot designed to help users learn key technology concepts through a simple conversational interface. The application combines Flask backend development with an attractive frontend built using HTML, CSS, and JavaScript.

The chatbot demonstrates how web technologies can be integrated with AI-related knowledge to create an engaging user experience.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/AI-Insight-Chatbot.git
```

### Navigate to Project Folder

```bash
cd AI-Insight-Chatbot
```

### Install Dependencies

```bash
pip install flask pyngrok
```

### Run Application

```bash
python app.py
```

### Open in Browser

```text
http://127.0.0.1:5000
```

For Google Colab users, open the generated ngrok URL.
